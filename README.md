# Ajit Kumar — Personal Portfolio

A responsive, dark minimal portfolio made with HTML, CSS and vanilla JavaScript.

## Files
- `index.html` — page structure and content
- `style.css` — styling and responsive layouts
- `script.js` — mobile menu, rotating role text, current year and back-to-top button
- `images/profile.jpg` — add your own profile photo here

## Before publishing
1. Add your photo as `images/profile.jpg` (JPG or JPEG).
2. In `index.html`, replace `your.email@example.com` with your real email.
3. Replace the GitHub and LinkedIn placeholder URLs with your profiles.
4. Replace `College / University name` with your actual institution.
5. Review the project descriptions and only keep details that accurately describe your work.

## Run locally
Open `index.html` in a browser, or use the Live Server extension in VS Code.

## Publish with GitHub Pages
1. Create a GitHub repository named `ajit-portfolio`.
2. Upload all files and the `images` folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait for deployment and open the URL shown in the Pages section.

Your URL will look like `https://ajitkumar.github.io/ajit-portfolio/`.
